# 초기 준비 검증 기록

점검일: 2026-11-02. Windows 11, Flutter 3.47.5, Dart 3.13.4, Java 21, Node.js 24 환경이다.

| 항목 | 결과 |
| --- | --- |
| Dart 정적 분석 | 통과, 문제 없음 |
| Flutter 단위·화면 테스트 | 8개 통과 |
| Firebase Emulator 보안 규칙 | 12개 통과 |
| Android APK 빌드 | 통과, debug APK 생성 |
| Android 체험 모드 통합 테스트 | 1개 통과, 게시판 선택 → 글 작성 → 상세 이동 |
| Android Firebase Emulator SDK 통합 테스트 | 1개 통과, 익명 인증·글·댓글·공감 토글·신고 저장 |
| iOS 빌드/실행 | 미실행, Mac/Xcode 필요 |
| 실제 두 기기/실제 Firebase 프로젝트 | 미실행 |
| 실제 온디바이스 AI | 미구현·미실행 |

보안 규칙 검사에서 일반·전각 공백과 이모지 길이의 앱/서버 차이를 발견해 수정하고 재실행했다. 익명 UID 위조, 다른 사용자의 공감 삭제, 신고 내용 조회, 임의 필드 삽입을 차단하는지도 확인했다.

Android 검증 기기는 로컬 `Pixel_6` 가상 기기(Android API 37, 16KB 페이지, RAM 4GB)이다. 체험 모드 통합 테스트와 Firebase SDK 통합 테스트는 각각 별도로 실행했다. 실제 두 기기의 동기화나 실기기 성능을 대신하는 결과는 아니다.

Firebase 통합 검사에서는 명명된 데모 앱만 초기화하면 Firestore 기본 앱이 없다는 오류가 발생하는 것을 확인했다. `[DEFAULT]` 데모 앱을 명시하고 실제 프로젝트 ID가 섞이지 않도록 확인한 뒤 재실행해 통과했다. Firestore Emulator 호스트를 유지하도록 설정 순서도 정리했다.

Git 제외 규칙은 lockfile·Gradle wrapper·Firebase 규칙·테스트 fixture·환경 예제가 추적되고, 빌드 산출물·루트 에뮬레이터 데이터·개인 자격 증명 폴더가 제외되는지 확인했다.

실기기 성능이나 아직 수행하지 않은 보고서 항목은 통과로 표시하지 않는다.

## 2026-11-09 MP1 프론트 검증

| 항목 | 결과 |
| --- | --- |
| Dart 포맷·정적 분석 | 통과 |
| Flutter 단위·화면 테스트 | 10개 통과. 저장 실패 시 입력 유지, 너비 320에서 글자 200%와 키보드 영역 확인 |
| Firestore 규칙 | 로컬 Emulator에서 13개 통과. 선택 제목 50자 검증 포함 |
| Android 체험 통합 | Pixel 6 가상 기기에서 더미 글 10개, 작성 후 `방금 전`, 해당 글 상세 확인 |
| Android Firebase 통합 | 로컬 익명 인증과 제목·본문·댓글·공감·신고 저장 확인 |

Android 체험 통합 테스트는 첫 실행에서 디버그 연결 로그 읽기가 중단되었고 재실행에서 통과했다. iOS, 운영 Firebase 프로젝트, 온디바이스 AI 모델은 이번 MP1 검증 범위에서 제외했다.
